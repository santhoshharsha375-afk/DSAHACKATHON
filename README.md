

# 📖 Overview

**ShopSmart** is a console-based e-commerce management system developed in Java as part of a **Data Structures Hackathon**.

The project demonstrates how fundamental data structures can be applied to solve real-world problems such as product inventory management, shopping cart operations, order processing, warehouse organization, and customer support.

Instead of relying heavily on Java's built-in collection classes, the project focuses on implementing custom data structures to strengthen understanding of their internal working and practical applications.

- Product Inventory Management
- Product Search by ID
- Product Search by Name
- Shopping Cart Management
- Undo Last Cart Operation
- Order Placement
- Normal Order Processing
- Express Order Processing using Priority Queue
- Delivery Slot Allocation
- Customer Support Ticket Management
- Warehouse Inventory Organization
- Interactive Console-Based Menu

# 🛠️ Data Structures Implemented

The project demonstrates the implementation and application of the following data structures:

- Linked List
- Stack
- Queue
- Circular Queue
- Hash Map
- Max Heap
- Arrays
- Bubble Sort

These data structures are integrated into different modules to simulate real-world e-commerce operations.
